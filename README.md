# BrokerReport

Анализ брокерских отчётов (HTML) с веб-интерфейсом и SQLite.

## Быстрый старт

```powershell
# Установка зависимостей
pip install flask beautifulsoup4 lxml firebase-admin

# Запуск
python run.py
```

Откройте http://127.0.0.1:5000

## Как это работает

1. HTML-отчёты брокера кладутся в папку `reports/`
2. При запуске скрипт автоматически импортирует все `.html`/`.HTML` файлы в SQLite
3. Фоновый дозор раз в минуту проверяет новые файлы
4. На дашборде — прибыль/убыток по трейд-сделкам (LIFO), открытые позиции, расходы на РЕПО
5. Фильтр по датам позволяет выбирать период для анализа
6. **Репликация БД в Firebase Storage** (опционально) — бекап и синхронизация между устройствами

## Репликация в Firebase Storage

Проект поддерживает автоматическую репликацию `broker.db` в Firebase Storage.
При каждом изменении данных (импорт/удаление отчёта) БД загружается в облако.
При запуске — скачивается последняя версия из облака (если есть).

Настройка — через файлы внутри `app/`, никаких переменных окружения не нужно.

### Настройка

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/)
2. Перейдите в **Project settings → Service accounts**
3. Нажмите **Generate new private key** — скачайте JSON-файл
4. Включите **Storage** в Firebase (режим — по умолчанию)
5. Сохраните скачанный JSON-файл как **`app/firebase-key.json`**

Готово! При следующем запуске репликация включится автоматически.

Если ключ не нужен — просто удалите файл, приложение работает как обычно.

### Как работает

| Событие | Действие |
|---------|----------|
| Запуск приложения | Скачивает `broker.db` из Firebase → локально |
| Импорт отчёта (вручную или авто) | Загружает локальный `broker.db` → Firebase |
| Удаление отчёта | Загружает локальный `broker.db` → Firebase |
| Фоновый дозор новых файлов | Загружает локальный `broker.db` → Firebase |
| Фоновый sync (каждые 5 мин) | Загружает локальный `broker.db` → Firebase |

### Файл конфигурации

Все параметры репликации задаются в `app/firebase_config.py`:

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `SERVICE_ACCOUNT_PATH` | `app/firebase-key.json` | Путь к JSON-ключу |
| `STORAGE_BUCKET` | авто из `project_id` | Имя Storage bucket |
| `DB_KEY` | `broker.db` | Имя файла в облаке |
| `SYNC_INTERVAL` | `300` (5 мин) | Интервал фоновой синхронизации |

### Безопасность

- `firebase-key.json` добавлен в `.gitignore` — не попадёт в репозиторий
- В Firebase Storage настройте **Security Rules**, разрешив запись только сервисному аккаунту
- При клонировании проекта на другой хост — просто скопируйте `firebase-key.json` в `app/`
